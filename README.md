A travel poster for AURELIA, a place that does not exist: garden terraces floating above a sea of clouds at golden hour, with one waterfall falling from terrace to terrace and a small airship drifting past the low sun. The program draws the poster with code and writes it as a deterministic 1024x1024 PNG.

## Run it

```sh
node main.ts
```

The poster is written to `/output/entry.png` (or `$MAKEFUN_OUTPUT_DIR/entry.png` when set). Node 22, standard library only, no network, no install step.
